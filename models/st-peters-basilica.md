# 성 베드로 대성당 — 창작 설계

## 확정한 방향

- 목표: 성 베드로 대성당 본관과 열쇠 모양 광장을 독자적인 브릭 상품으로 설계한다. 1차는 본관·정면 연결 공간·직선 및 곡선 회랑·광장 바닥·오벨리스크·분수이며, 옆 부속 건물과 뒤 정원은 이후 범위다.
- 본관 단독으로도 충분한 디테일과 완성된 외형을 갖추고, 회랑·광장은 같은 축척의 확장 제품으로 분리할 수 있게 한다. 광장을 포함한 전체 길이 때문에 본관을 축소하지 않는다.
- 기본 검토 축척은 약 1:280이다. 1:270·1:250으로 변경하라는 지시는 없으며, 구체적인 부품 조합·화면 비교에서 필요성이 확인되면 축소보다 확대를 우선 제안한다.
- 실측과 반복 수의 완전 일치보다 닮은 인상을 우선한다. 창·기둥 개수 축약, 강조할 부위의 확대와 비강조 부위 압축을 허용한다. 실루엣·중앙부 강조·대칭·열린 공간·리듬을 보존한다. 부품 자체를 늘이거나 비틀지는 않는다.
- 원본: `models/st-peters-basilica-v1.mpd`. 기존 LEGO 제품 재구성이 아닌 GoBricks 부품 기반 창작이므로 v1로 시작한다. 현재는 로컬 조립 표본이며 전체 건축물이나 판매 가능한 완성품이 아니다.
- 초기 석재·지붕 색상과 창의 표현은 시험값이다. 제품 색상과 돔·정면 세부 비례는 표본을 보고 결정한다. 본격 내부 재현·개방 기능·조명·가격 상한은 아직 확정하지 않았으며 외관 표본 제작을 막지 않는다.

## 좌표와 통합

- LDraw 단위: 1스터드=20 LDU=8mm, 브릭 높이=24 LDU, 플레이트 높이=8 LDU.
- X는 정면 좌우, -Y는 위, +Z는 정면에서 건물 뒤쪽이다. 로컬 표본은 바닥 Y=0을 사용한다.
- 현재 루트는 부위별 표본을 떨어뜨려 보여주는 검토 배치다. 표본 사이의 거리는 건물 치수·접속 좌표가 아니다. 최종 본관·광장 배치는 아직 동결하지 않았다.
- 메인이 돔의 실제 조립 폭과 정면 표본의 시각적 리듬을 비교해 본관 폭·높이와 접속면을 확정한다. 그 전에는 기본 축척을 지켰다는 이유만으로 정밀한 전체 좌표를 만들어 넣지 않는다.
- 반복 호출의 ID 모호성을 피하도록 배치별 물리 부품 ID를 고유하게 사용한다. 루트는 메인이 소유하며 에이전트는 지정 섹션과 자기 상태 항목만 제출한다. 담당 배치를 추가한 자기 브랜치에서는 검증용 수량·SKU 수·가격·관측 외곽 등 파생 집계를 실제 본문에 맞춰 갱신할 수 있다. 다른 담당의 형상·상태 의미는 바꾸지 않으며 최종 집계는 메인이 통합 후 다시 계산한다.

## 최초 표본과 판정

- 첫 공유본은 돔 곡률·정면 창 세 칸·직선 열주의 세 로컬 조립 표본이었다. 현재 공유 설계본은 3,027개 배치·51개 판매 SKU·487.45 CNY의 공개 단품가 합계다. 이는 임시 표본 전체 집계이지 본관 부품 수나 최종 제품 견적이 아니다. 전시 레이아웃 범위 81.6×26.72×70.8cm도 성당 제품 치수가 아니다.
- GoBricks 상품·색상·관측 재고, 형상 참조·해시·ID·수량·회전과 직육면체 몸체 명목 겹침 검사는 통과했다. 별도 명목 스터드 격자 접점 그래프에서 각 표본은 각각 하나의 연결 성분이다. 이 검사는 실제 클러치·모든 곡면의 간섭·하중 안정성 검증이 아니다.
- 첫 수평 플레이트 적층 돔은 계단과 격자 패턴이 거칠고 드럼·랜턴 비례도 더 검토해야 한다. 상품 외피나 최종 돔 규격으로 채택하지 않는다. 메인이 타지마할식 측면 조립·곡면 부품과 세로 골을 포함한 방법을 다음으로 비교한다. 색상으로 표시한 리브를 실제 돌출 리브 완성으로 세지 않는다.
- 정면과 열주는 에이전트 A·D의 개선 출발점이다. 반복 수·창 폭·층 높이·기둥 간격을 최종 건물에 강제하지 않는다. B·C·E의 빈 FILE 섹션은 담당 구역의 작업 자리이며 완료 범위가 아니다.
- 새 성당 표본은 공유 설계 브랜치에 보존한다. 기존 모델 5종의 사이트 게시와 구분하며, 사용자 검토 전 완성된 성당 상품처럼 게시하지 않는다.

## 메인 — 힌지 곡면 띠 비교

기존 수평 적층 표본과 다른 방법으로 4개 패널을 실제 4275b/4276b 힌지로 연결한 세 가지 세로 곡률 띠를 추가했다. 각 띠는 받침·기부·힌지·3020 패널·15068 곡면 외피를 포함한 23개 부품이다. 각 패널은 곡면 방향을 띠 폭 방향으로 배치해 높이 방향의 반복 경사턱을 줄였다. 부티크 호텔 설명서의 옆면 부착 곡면 패널 구조도 확인했다. 그 작은 돔의 비례나 전용 형상을 그대로 확대한 모델은 아니다.

- 완만한 안: 패널 절대 기울기 70/55/40/25도.
- 중간 안: 80/65/45/25도. 세 안 중 돔의 솟는 인상을 다음으로 발전시킬 우선 후보다.
- 높은 안: 80/70/55/35도. 상대적으로 첨탑처럼 보일 가능성이 있어 비교 대상으로 유지한다.

12개 힌지 짝의 중심과 축을 원본 DAT 하위 변환에서 계산했다. 중심 잔차는 0.000001 LDU 미만이고 축은 평행하다. 각 곡면 부품의 아래쪽 스터드 격자 4곳이 패널과 맞으며, 명목 접점 그래프에서 각 띠는 하나로 연결된다. 초기 기부–회전 부품의 교차 후보는 기부를 한 브릭 높인 뒤 재검사했다. 회전된 인접 부품의 면 접촉을 로컬 축 투영으로 구분한 후, 의도된 힌지·스터드 짝을 제외한 BVH 표면 교차 후보는 0쌍이다. 전체 상태·판매 대응·해시 검사와 명목 직육면체 겹침 검사도 통과했다.

이는 지정한 세 자세의 기하 표본이다. 힌지는 각도를 고정하는 프레임이 없고, 방사형 패널 사이를 메우는 쐐기 폭과 실제 돌출 리브도 아직 설계하지 않았다. 자립 돔·무간섭 가동·실물 유지력·하중 검증을 주장하지 않는다. 기본 축척과 다른 담당의 기존 FILE 섹션은 바꾸지 않았다. 다음 메인 과제는 우선 곡률 후보를 받치는 고정 프레임과 폭이 변하는 외피 조립이다.

## B 본당 16×12스터드 양쪽 외벽·지붕 표본

- `sp-nave-study.ldr`의 외벽은 각각 X방향 16스터드 길이, 2스터드 두께, 네 단의 2×2 브릭이다. 창 두 칸 폭의 개구를 세 개씩 반복하고, 외벽 중심은 로컬 Z=−80과 +80 LDU다. 두 벽 안쪽 면 사이는 120 LDU(6스터드)다. 지붕의 바깥 경계는 320×240 LDU(16×12스터드)이며 처마가 외벽 바깥으로 한 스터드씩 나온다.
