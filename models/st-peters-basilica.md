# 성 베드로 대성당 — 창작 설계

## 확정한 방향

- 목표: 성 베드로 대성당 본관과 열쇠 모양 광장을 독자적인 브릭 상품으로 설계한다. 1차는 본관·정면 연결 공간·직선 및 곡선 회랑·광장 바닥·오벨리스크·분수이며, 옆 부속 건물과 뒤 정원은 이후 범위다.
- 본관 단독으로도 충분한 디테일과 완성된 외형을 갖추고, 회랑·광장은 같은 축척의 확장 제품으로 분리할 수 있게 한다. 광장을 포함한 전체 길이 때문에 본관을 축소하지 않는다.
- 기본 검토 축척은 약 1:280이다. 1:270·1:250으로 변경하라는 지시는 없으며, 구체적인 부품 조합·화면 비교에서 필요성이 확인되면 축소보다 확대를 우선 제안한다.
- 실측과 반복 수의 완전 일치보다 닮은 인상을 우선한다. 창·기둥 개수 축약, 강조할 부위의 확대와 비강조 부위 압축을 허용한다. 실루엣·중앙부 강조·대칭·열린 공간·리듬을 보존한다. 부품 자체를 늘이거나 비틀지는 않는다.
- 원본: `models/st-peters-basilica-v1.mpd`. 기존 LEGO 제품 재구성이 아닌 GoBricks 부품 기반 창작이므로 v1로 시작한다. 현재는 로컬 조립 표본이며 전체 건축물이나 판매 가능한 완성품이 아니다.
- 초기 석재·지붕 색상과 창의 표현은 시험값이다. 제품 색상과 돔·정면 세부 비례는 표본을 보고 결정한다. 본격 내부 재현·개방 기능·조명·가격 상한은 아직 확정하지 않았으며 외관 표본 제작을 막지 않는다.

## 5개 대기 에이전트의 담당

모두 자기 브랜치에서 같은 MPD의 지정 내부 섹션만 수정한다. 시작 시 최신 main 정책과 이 기록을 읽는다. 부품 ID는 담당 접두어로 구분한다. 공용 사전 수정은 메인이 조율하며, 새 형상은 필요한 경우만 기존 위치에 추가한다. 전체 MPD를 다른 브랜치의 파일로 덮어쓰지 않는다.

| 담당 | 내부 섹션 접두어 / 부품 ID | 첫 과제 | 경계 |
|---|---|---|---|
| 메인 | `sp-dome-` / `M-` | 대돔 윤곽·세로 골·랜턴의 조립 시험, 전체 비례·접속 규격·최종 통합 | 기본 축척과 최종 루트 배치·통합 상태를 관리 |
| A 정면 | `sp-front-` / `A-` | 기존 창·기둥 표본을 개선해 중앙 입면의 깊이·처마·큰 기둥 표현 비교 | 본당·돔·광장 수정 금지 |
| B 본당 | `sp-nave-` / `B-` | 직선 외벽·창·처마와 탈착 가능한 지붕의 짧은 로컬 조립 | 전체 길이·정면 및 돔 접속 위치 임의 확정 금지 |
| C 교차부·후진 | `sp-crossing-` / `C-` | 본당과 대돔을 받치는 교차부 및 곡선 후진의 접속 표본 | 메인 돔 외피·드럼 규격 임의 변경 금지 |
| D 직선 회랑·광장 | `sp-square-` / `D-` | 수평 보가 있는 짧은 직선 열주와 광장 바닥 경계 표본 | 전체 광장 크기·곡선 회랑 각도 임의 확정 금지 |
| E 곡선 회랑 | `sp-colonnade-` / `E-` | 수평 보·기둥·지붕을 가진 소수 반복 구간의 곡선 연결 시험 | 본관 축척 변경·콜로세움식 반복 아치로 대체 금지 |

첫 결과는 각자 실제로 연결된 로컬 표본과 정면·측면·사선 비교, 사용 부품·색상, 접점과 남은 문제다. 조사·문서만 수정하고 종료하지 않는다. 표본 과제를 끝내면 메인이 통합 규격을 정할 수 있게 보고하며 임의로 전체 구역을 확장하지 않는다. 다음 단계는 확인된 규격으로 각 구역을 확장하는 것이다. 대기 중인 외부 에이전트에게 실제 지시 전달은 사용자가 수행한다.

## 좌표와 통합

- LDraw 단위: 1스터드=20 LDU=8mm, 브릭 높이=24 LDU, 플레이트 높이=8 LDU.
- X는 정면 좌우, -Y는 위, +Z는 정면에서 건물 뒤쪽이다. 로컬 표본은 바닥 Y=0을 사용한다.
- 현재 루트는 부위별 표본을 떨어뜨려 보여주는 검토 배치다. 표본 사이의 거리는 건물 치수·접속 좌표가 아니다. 최종 본관·광장 배치는 아직 동결하지 않았다.
- 메인이 돔의 실제 조립 폭과 정면 표본의 시각적 리듬을 비교해 본관 폭·높이와 접속면을 확정한다. 그 전에는 기본 축척을 지켰다는 이유만으로 정밀한 전체 좌표를 만들어 넣지 않는다.
- 반복 호출의 ID 모호성을 피하도록 배치별 물리 부품 ID를 고유하게 사용한다. 루트는 메인이 소유하며 에이전트는 지정 섹션과 자기 상태 항목만 제출한다. 담당 배치를 추가한 자기 브랜치에서는 검증용 수량·SKU 수·가격·관측 외곽 등 파생 집계를 실제 본문에 맞춰 갱신할 수 있다. 다른 담당의 형상·상태 의미는 바꾸지 않으며 최종 집계는 메인이 통합 후 다시 계산한다.

## 최초 표본과 판정

- 첫 공유본은 돔 곡률·정면 창 세 칸·직선 열주의 세 로컬 조립 표본이다. 2,741개 배치·34개 판매 SKU는 세 표본의 합이며 본관 부품 수나 최종 제품 견적이 아니다. 표본 전체 전시 범위 56.0×22.4×26.72cm도 성당 제품 치수가 아니다.
- 정면 비교 표본: 기존안 A(292개)는 한 층 세 칸씩 작은 아치창을 반복하고 1×1 원형 기둥 6개를 뒀다. 검토 커밋 `7c6aa0f`는 직전 B안에서 재현한 86쌍의 명목 몸체 겹침과 중앙축을 막는 기둥을 지적했다. 이를 반영한 새 B안(198개)은 한 층 양쪽에 4스터드 폭 창을 두고, 중앙에는 4스터드 출입구와 그 위 발코니 개구를 열었다. 두 중앙 기둥이 그 개구를 감싸며 바깥쪽 기둥 두 개가 양쪽 창 베이를 받친다. B는 A의 18스터드보다 넓은 20스터드 국소 비교 범위지만, 전체 정면 폭을 정한 것은 아니다.
- 창틀(z=70)은 벽 중심(z=50)보다 20 LDU 뒤에 두고 어두운 벽감 면(z=90)까지 연결했다. 아치 몰딩(z=50)은 벽면에 맞추고, 2×2 원형 기둥 4개(3941, 탄색)는 벽 앞쪽에 배치했다. 각 기둥은 1×2 결속 벽돌을 통해 벽과 접하고, 수평 처마 띠와 창턱·발코니 바닥은 벽 전면에 면 접촉하도록 조정했다. 전후 화면에서 B는 중앙 기둥으로 축을 막지 않으며, 넓은 창·깊은 기둥과 중앙 출입구·발코니가 함께 읽힌다.
- 전후 동일 시점에서 중앙 개구와 기둥 간격을 비교했다. B의 명목 직육면체 몸체 겹침은 기존 86쌍에서 0쌍으로 줄었다. 접점 좌표도 확인했으나 이는 부품 경계·명목 격자 검사이며 실제 클러치, 아치 형상의 정밀 간섭, 하중 안정성은 미검증이다. B는 198개, 8개 GoBricks SKU, 관측 단가 합계 42.72 CNY의 국소 표본이며 다음 정면 설계의 비교안이다. 전체 정면의 창 수·폭과 본당 결합 규격은 확정하지 않는다.
- 현재 공유 모델에는 A와 B를 나란히 둔 정면 표본이 포함되어 있다. 전체 작업본 집계는 2,939개 배치·36 SKU·457.06 CNY이며, 돔·정면·열주 표본과 정면 비교안의 합계다. 전시용 비교 배치를 포함하므로 성당 본체 수량·크기·견적을 뜻하지 않는다.
- GoBricks 상품·색상·관측 재고, 형상 참조·해시·ID·수량·회전과 직육면체 몸체 명목 겹침 검사는 통과했다. 별도 명목 스터드 격자 접점 그래프에서 각 표본은 각각 하나의 연결 성분이다. 이 검사는 실제 클러치·모든 곡면의 간섭·하중 안정성 검증이 아니다.
- 첫 수평 플레이트 적층 돔은 계단과 격자 패턴이 거칠고 드럼·랜턴 비례도 더 검토해야 한다. 상품 외피나 최종 돔 규격으로 채택하지 않는다. 메인이 타지마할식 측면 조립·곡면 부품과 세로 골을 포함한 방법을 다음으로 비교한다. 색상으로 표시한 리브를 실제 돌출 리브 완성으로 세지 않는다.
- 정면과 열주는 에이전트 A·D의 개선 출발점이다. 반복 수·창 폭·층 높이·기둥 간격을 최종 건물에 강제하지 않는다. B·C·E의 빈 FILE 섹션은 담당 구역의 작업 자리이며 완료 범위가 아니다.
- 새 성당 표본은 공유 설계 브랜치에 보존한다. 기존 모델 5종의 사이트 게시와 구분하며, 사용자 검토 전 완성된 성당 상품처럼 게시하지 않는다.
