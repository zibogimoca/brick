# 성 베드로 대성당 — 창작 설계

## 보관 상태 — 사용자 지시로 작업 중단

이 프로젝트는 완성 판정 없이 중단·보관한다. 사용자는 BrickLink Designer Program 출품을 목표로 했으나 종교 건물 제한을 확인했다고 알렸고, 다음 주제를 아서왕의 카멜롯으로 변경했다. 사용자가 명시적으로 재개하기 전에는 성당 설계·에이전트 과제를 자동으로 계속하지 않는다. 기존 모델·공용 부품·검증 도구는 보존한다.

최종 보관 기준은 Git 태그 `archive/st-peters-basilica-v1`이다. 새 관리 파일은 만들지 않는다. 메인 돔 기준은 `280bbb1`, 마지막 담당 반영은 아래 표의 커밋이다. 다섯 원격 제출 브랜치의 마지막 푸시를 확인했고 미반영 B/C를 추가 회수했다. 루트 전시 배치와 메인 돔 형상은 유지했다.

재개 시에는 이 절과 현재 검토 표를 먼저 읽고 아래 순서로 진행한다.

1. 태그와 최신 main의 차이 및 작업 트리를 확인하고 기존 배치를 보존한다. 파일 존재 여부·과거 SKU 오류 조사를 처음부터 반복하지 않는다.
2. 부위별 표본을 최종 성당으로 연결하기 전에 전체 실루엣·비례·축척과 접속 규격을 먼저 결정한다. 기본1:280은 검토값이며 표본 전시 간격은 실제 건물 배치가 아니다.
3. 메인 돔은 세로 외피 틈·정상부 랜턴·C 교차부 접속이 남아 있다. B의 반대쪽 측랑, A/B/C의 최종 접합, 광장 전체 곡률·바닥·분수·오벨리스크도 미완료다.
4. 검증된 창의 깊이·힌지 접점·점퍼 배치·탈착 모듈 기법을 재사용한다. 성당 고유의 부품·비례를 다음 카멜롯의 확정 규격으로 취급하지 않는다.

## 확정한 방향

- 목표: 성 베드로 대성당 본관과 열쇠 모양 광장을 독자적인 브릭 상품으로 설계한다. 1차는 본관·정면 연결 공간·직선 및 곡선 회랑·광장 바닥·오벨리스크·분수이며, 옆 부속 건물과 뒤 정원은 이후 범위다.
- 본관 단독으로도 충분한 디테일과 완성된 외형을 갖추고, 회랑·광장은 같은 축척의 확장 제품으로 분리할 수 있게 한다. 광장을 포함한 전체 길이 때문에 본관을 축소하지 않는다.
- 기본 검토 축척은 약 1:280이다. 1:270·1:250으로 변경하라는 지시는 없으며, 구체적인 부품 조합·화면 비교에서 필요성이 확인되면 축소보다 확대를 우선 제안한다.
- 실측과 반복 수의 완전 일치보다 닮은 인상을 우선한다. 창·기둥 개수 축약, 강조할 부위의 확대와 비강조 부위 압축을 허용한다. 실루엣·중앙부 강조·대칭·열린 공간·리듬을 보존한다. 부품 자체를 늘이거나 비틀지는 않는다.
- 원본: `models/st-peters-basilica-v1.mpd`. 기존 LEGO 제품 재구성이 아닌 GoBricks 부품 기반 창작이므로 v1로 시작한다. 현재는 로컬 조립 표본이며 전체 건축물이나 판매 가능한 완성품이 아니다.
- 초기 석재·지붕 색상과 창의 표현은 시험값이다. 제품 색상과 돔·정면 세부 비례는 표본을 보고 결정한다. 본격 내부 재현·개방 기능·조명·가격 상한은 아직 확정하지 않았으며 외관 표본 제작을 막지 않는다.

## 좌표와 통합

- LDraw 단위: 1스터드=20 LDU=8mm, 브릭 높이=24 LDU, 플레이트 높이=8 LDU.
- X는 정면 좌우, -Y는 위, +Z는 정면에서 건물 뒤쪽이다. 로컬 표본은 바닥 Y=0을 사용한다.
- 현재 루트는 부위별 표본을 떨어뜨려 보여주는 검토 배치다. 표본 사이의 거리는 건물 치수·접속 좌표가 아니다. 최종 본관·광장 배치는 아직 동결하지 않았다.
- 메인이 돔의 실제 조립 폭과 정면 표본의 시각적 리듬을 비교해 본관 폭·높이와 접속면을 확정한다. 그 전에는 기본 축척을 지켰다는 이유만으로 정밀한 전체 좌표를 만들어 넣지 않는다.
- 반복 호출의 ID 모호성을 피하도록 배치별 물리 부품 ID를 고유하게 사용한다. 루트는 메인이 소유하며 에이전트는 지정 섹션과 자기 상태 항목만 제출한다. 담당 배치를 추가한 자기 브랜치에서는 검증용 수량·SKU 수·가격·관측 외곽 등 파생 집계를 실제 본문에 맞춰 갱신할 수 있다. 다른 담당의 형상·상태 의미는 바꾸지 않으며 최종 집계는 메인이 통합 후 다시 계산한다.

## 접점 설계의 유지 조건

- 정면의 후퇴 창·장식은 실제 받침 깊이와 스터드 격자를 유지한다. 중앙 개구·발코니 안쪽을 마감 부품으로 막지 않는다.
- 지붕 내부 연결판·용마루의 두께 변화는 착좌 높이에 함께 반영한다. 경사·창틀·힌지는 직육면체 검사만으로 판단하지 않는다.
- 옆 스터드87087, 경사3039/30363의 실제 스터드 위치와34103중앙 홀더는 공용 검사에 반영돼 있다.3941에 존재하지 않는 중앙 스터드를 만들어 연결망을 통과시키지 않는다.

## 메인 돔

곡면 기법 비교용 `sp-dome-locking-gore-study.ldr`은 72개 조립체다. 현재 주 표본은 아래 12방사 돔·드럼이다. 두 줄의 44301/44302 클릭 힌지를 가로판으로 묶고 패널 기울기를 67.5/67.5/45/22.5도로 두었다. 폭은 6→6, 6→4, 4→2, 2→2스터드로 변화하며 쐐기 외피와 돌출 띠·이음부 덮개·상부 접속판을 포함한다. 168개 명목 스터드 대응과 힌지 10쌍이 하나로 연결되고 비결합 표면 교차 후보는 0쌍이다.
