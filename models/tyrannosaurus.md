# 티라노사우루스 설계·개선 기록

## 기준과 목표

- 형상 원본: `tyrannosaurus.mpd`.
- 최소 기준 제품: [LEGO 76968 Dinosaur Fossils: Tyrannosaurus rex](https://www.lego.com/ko-kr/product/dinosaur-fossils-tyrannosaurus-rex-76968). 사용자가 지정한 기술·외형의 최소 수준이며 그대로 복제할 대상은 아니다.
- 공식 제품 설명 확인: 높이 33cm, 1:12 스케일, 3,145개 부품. 머리·턱·팔/손·꼬리의 가동과 전시 스탠드를 명시한다. 정확한 가동각·지지대 수·내부 구조는 설명서 분석 전이므로 미확인이다.
- 공식 페이지에서 전장·폭 수치는 확인하지 못했다. 상품 포장 치수나 이미지 해상도를 완성 모델의 크기로 사용하지 않는다.
- 목표: 티라노 화석으로 읽히는 외형과 기준 제품보다 다양한 자세. 모든 부위를 가동할 필요는 없지만 목·꼬리·다리·턱의 필요한 움직임을 검토한다.
- 안정성: 가능하면 자립, 그렇지 않으면 지지대 수와 시각적 방해를 줄인다. 가동성을 늘리면서 지지 조건이나 외형을 악화시키는 타협은 먼저 논의한다.
- 크기 목표: 기본 전시 자세에서 주둥이 끝부터 꼬리 끝까지 약 110cm, 발바닥부터 가장 높은 골격까지 약 38cm. 스탠드·명판은 제외한다. 완성 모델의 측정값이 아니라 새 설계 목표다. 폭은 흉곽·골반 비례와 발 간격에 맞춰 결정한다.
- 크기 결정 근거: 사용자는 기준 제품과 비슷하거나 더 큰 크기를 원한다. 공식 높이 33cm보다 약 15% 높은 38cm를 목표로 하되, 전체 형상을 일괄 확대하거나 개별 브릭의 실제 크기를 늘리지 않는다. 실제 판매 부품의 수와 결합으로 크기를 구성한다.
- 부품 수·예산·허용 지지대 수의 구체적 목표는 미정이다.

## 현재 평가와 실패에서 남길 내용

| 문제 | 근거·확인 수준 | 다음 설계에 적용할 교훈 |
| --- | --- | --- |
| 화석다운 외형 부족 | 사용자 평가: 갈비뼈·등뼈 표현이 부족하고 공룡 골격으로 보이지 않음 | 두개골 윤곽·빈 공간, 입체 흉곽, 척추와 돌기, 골반·다리 비례를 기준 제품과 비교해야 함 |
| 다양한 자세를 위한 설계 부족 | 현재 사례는 고정 자세 설계로 기록됨; 목표 가동 범위는 아직 검증하지 않음 | 외형 완성 후 관절을 끼우지 말고 연출할 자세와 골격·관절·외형을 함께 설계 |
| 검사 통과를 완성도로 오인할 위험 | 기존 검사는 160개 배치·명목 격자 겹침·접촉 그래프·가격·참조 무결성을 확인함 | 외형 품질, 실제 가동 범위, 정밀 간섭, 실물 결합력·하중·자립을 별도로 평가 |

현재 개선 형상을 제작하거나 효과를 확인한 사례는 없다. 이 기록 정리는 모델 개선 완료를 뜻하지 않는다.

## 다음 논의·검토

1. LEGO 76968의 공식 이미지·설명서에서 외형, 관절, 지지 구조의 비교 기준을 확인한다.
2. 실제 티라노 골격 자료와 대조해 우선 개선할 부위와 원하는 자세를 정한다.
3. 사용자가 설계를 지시하면 두개골·갈비뼈·관절 등 중요한 부분의 대안을 먼저 시험하고 비교한다.
4. 확인된 결과만 문제·시도·효과·채택 이유로 갱신한다. 공통화 가능한 교훈만 `docs/design-experience.json`에 반영한다.

사용자가 새 티라노 모델 작업과 기준 제품과 비슷하거나 더 큰 크기를 승인했다. 현재 단계는 크기 목표와 공식 기준 확인이며, 기존 MPD 형상은 아직 새 설계로 교체하지 않았다. 이후 실제 모델 치수와 관절·외형 검토 결과로 이 기록을 갱신한다. 대화 전문이나 사소한 작업 이력은 이 파일에 쌓지 않는다.
