# 트리케라톱스 설계·개선 기록

## 사용자 지정 참고 자료

- 전체 화석 기준: [LEGO 77985 공룡 화석: 트리케라톱스](https://www.lego.com/ko-kr/product/dinosaur-fossils-triceratops-77985), [공식 설명서](https://www.lego.com/ko-kr/service/building-instructions/77985). 공식 설명서 페이지에서 제품명·1,154개 부품 확인.
- 두개골 결합 참고: [LEGO 76969 공룡 화석: 트리케라톱스 두개골 설명서](https://www.lego.com/ko-kr/service/building-instructions/76969). 공식 페이지에서 제품명·468개 부품 확인.

아직 모델 제작이나 설명서 내부 구조 분석을 시작하지 않았다. 티라노의 결합 사례를 검증 없이 이 모델의 성공 사례로 옮기지 않는다. 가동 범위·크기·지지 조건은 실제 자료 확인 후 정한다.
